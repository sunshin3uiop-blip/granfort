# GRANFORT

Простая адаптивная вёрстка по макету Figma. HTML, CSS (flex/grid), JavaScript без библиотек и анимаций.

## Открыть

Откройте `dist/index.html` в браузере. Сборка и установка зависимостей не нужны. Фотографии и шрифты хранятся локально в `dist/assets`.

## Файлы

- `dist/index.html` — разметка.
- `dist/style.css` — стили для компьютера и телефона.
- `dist/script.js` — поиск по услугам, меню, вопросы, выбор специалиста и информационные окна.

## Что работает

Навигация по разделам, поиск по трём услугам, карточки с переходом к письму, раскрытие ответов, выбор специалиста, адрес на карте, электронная почта. Окна с информацией о доставке, возврате, акциях и документах явно показывают, что соответствующий контент ещё не предоставлен. Серверной отправки заявок и авторизации нет.

## Отличия от макета

Мелкие иконки и монограмма упрощены: лимит Figma MCP закончился до их выгрузки. Основные фото, карта, шрифты, цвета, десктопная и мобильная композиции взяты из макета. Добавленные ответы в FAQ — демонстрационный текст, его нужно согласовать перед коммерческим использованием.

## Проверка

Проверены синтаксис JavaScript, локальные ссылки на ресурсы, якоря и отсутствие CSS-анимаций/переходов. Визуальная проверка в браузере недоступна в текущем окружении.
