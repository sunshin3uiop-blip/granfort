# GRANFORT

Простая адаптивная вёрстка по макету Figma. HTML, CSS (flex/grid), JavaScript и небольшой обработчик заявок на PHP. Без библиотек, базы данных и анимаций.

## Открыть

Нужен PHP 8 или новее. Из папки проекта выполните:

```sh
php -S 127.0.0.1:3000 -t dist
```

Откройте `http://127.0.0.1:3000`. Сборка и установка зависимостей не нужны. Фотографии и шрифты хранятся локально в `dist/assets`.

Без PHP можно открыть `dist/index.html` для просмотра вёрстки, но отправка заявок работать не будет. GitHub Pages также не выполняет PHP.

## Файлы

- `dist/index.html` — разметка.
- `dist/style.css` — стили для компьютера и телефона.
- `dist/script.js` — поиск по услугам, меню, вопросы, выбор специалиста и информационные окна.
- `dist/request.php` — принимает форму, проверяет поля и записывает заявку.
- `data/requests.jsonl` — сохранённые заявки; создаётся при первой отправке и не попадает в Git.

## Как работает PHP

Нажмите на карточку услуги или кнопку связи в шапке. Заполните имя и телефон, выберите услугу и нажмите «Оставить заявку». Форма отправляется обычным POST-запросом в `request.php`.

PHP проверяет имя, телефон и выбранную услугу. Если всё заполнено правильно, добавляет одну строку JSON в `data/requests.jsonl` и показывает сообщение об успехе. Старые заявки остаются в файле. Если данные неверные или запись не удалась, показывает ошибку.

На хостинге корнем сайта должна быть папка `dist`. Папка `data` должна оставаться за её пределами, а процесс PHP должен иметь право записи в неё. Посмотреть заявки можно, открыв файл `data/requests.jsonl` на сервере. Страницы администратора и отправки писем нет.

## Что работает

Навигация по разделам, поиск по трём услугам, форма заявки в карточках услуг и кнопке связи, сохранение заявок через PHP, раскрытие ответов, выбор специалиста, адрес на карте, электронная почта. Окна с информацией о доставке, возврате, акциях и документах явно показывают, что соответствующий контент ещё не предоставлен. Авторизации нет.

## Отличия от макета

Мелкие иконки и монограмма упрощены: лимит Figma MCP закончился до их выгрузки. Основные фото, карта, шрифты, цвета, десктопная и мобильная композиции взяты из макета. Добавленные ответы в FAQ — демонстрационный текст, его нужно согласовать перед коммерческим использованием.

## Проверка

Проверены синтаксис JavaScript и PHP, локальные ссылки на ресурсы, якоря и отсутствие CSS-анимаций/переходов. Обработчик PHP проверяется HTTP-запросами: сохранение нескольких заявок, неверные поля, неправильный метод запроса, недоступность файла заявок через сайт и ошибка записи. Визуальная проверка в браузере недоступна в текущем окружении.
